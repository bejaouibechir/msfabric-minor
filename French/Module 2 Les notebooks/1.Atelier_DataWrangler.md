### 4.3 — Standardiser la colonne timestamp

> ⚠️ **Piège** : la conversion **Change column type → DateTime** génère `df.astype({'timestamp': 'datetime64[ns]'})` qui échoue sur des formats mixtes comme ceux de ce fichier (`2025-01-03T04:30:00`, `17/01/2025 18:15:00`, `2025-01-22 01:00:00`). Il faut utiliser un **Custom transform**.

1. Dans le panneau gauche, chercher **Custom operation**
2. Cliquer **Custom operation**
3. Dans l'éditeur de code qui s'ouvre, saisir :

```python
import pandas as pd
df['timestamp'] = pd.to_datetime(df['timestamp'], format='mixed', dayfirst=True)
```

4. Cliquer **Apply**

**Ce que vous devez voir à l'écran** :

- toutes les dates s'affichent dans un format uniforme `YYYY-MM-DD HH:MM:SS`
- aucune erreur dans le panneau du bas
- l'opération apparaît dans **Cleaning steps** sous le nom `Custom transform`

> 💡 **Explication** : `format='mixed'` indique à pandas d'inférer le format ligne par ligne, ce qui gère les trois formats présents dans le fichier. `dayfirst=True` assure la bonne interprétation des dates au format `dd/MM/yyyy`.

## Partie 5 — Récupérer le code généré

Data Wrangler génère automatiquement le code Python de toutes les opérations effectuées.

1. Cliquer le bouton **Add code to notebook** en haut à droite
2. Data Wrangler insère une nouvelle cellule dans le notebook avec le code complet

**Exemple de code généré** :

```python
# Code generated by Data Wrangler for pandas DataFrame
import pandas as pd

def clean_data(df):
    # Filter rows based on column: 'status'
    df = df[df['status'] != "ERROR"]
    # Change column type to float64 for column: 'consumption_mw'
    df = df.astype({'consumption_mw': 'float64'})
    df['timestamp'] = pd.to_datetime(df['timestamp'], format='mixed', dayfirst=True)
    # Rename column 'consumption_mw' to 'consumption_MW'
    df = df.rename(columns={'consumption_mw': 'consumption_MW'})
    return df

df_clean = clean_data(df.copy())
display(df_clean)
```

> 💡 **Intérêt majeur** : le code est **réutilisable et versionnable**. Il peut être commité dans GitHub et intégré dans un pipeline de production.

## Partie 7 — Dédupliquer les lignes (Drop duplicate rows)

**Scénario** : le capteur a retransmis certaines mesures (timeout réseau). Le fichier contient des **lignes strictement identiques** (même `timestamp`, `site_id`, mesures et `status`). Le filtre `ERROR` de la Partie 4 ne les supprime pas.

### 7.1 — Mesurer les doublons

Dans une nouvelle cellule :

```python
print("Lignes :", len(df_clean))
print("Doublons exacts :", df_clean.duplicated().sum())
```

**Ce que vous devez voir à l'écran** :

- `Lignes : 17271`
- `Doublons exacts : 821`

### 7.2 — Dédupliquer avec Data Wrangler

1. Cliquer sur la cellule contenant `df_clean`
2. **Data** → **Launch Data Wrangler** → choisir **`df_clean`**
3. Dans le panneau gauche, chercher **Drop duplicate rows**
4. Laisser toutes les colonnes sélectionnées (un doublon = toutes les colonnes identiques)
5. Cliquer **Apply**
6. Cliquer **Add code to notebook**
7. Dans la cellule générée, renommer la fonction et le DataFrame de sortie pour ne pas écraser `df_clean` :

```python
def dedup_data(df_clean):
    # Drop duplicate rows across all columns
    df_clean = df_clean.drop_duplicates()
    return df_clean

df_dedup = dedup_data(df_clean.copy())
display(df_dedup)
```

**Ce que vous devez voir à l'écran** :

- le nombre de lignes passe de **17 271 à 16 450**
- l'opération apparaît dans **Cleaning steps** sous le nom `Drop duplicate rows`

### 7.3 — Vérifier en Python

```python
print("Lignes :", len(df_dedup))
print("Doublons restants :", df_dedup.duplicated().sum())
print("Doublons sur (timestamp, site_id) :", df_dedup.duplicated(subset=["timestamp", "site_id"]).sum())
```

Résultat attendu : `16450`, `0`, `0`.

> 💡 **Pour aller plus loin** : `drop_duplicates(subset=["timestamp", "site_id"], keep="last")` déduplique sur une **clé métier** (une seule mesure par site et par instant) au lieu de comparer toutes les colonnes. Dans Data Wrangler, il suffit de ne sélectionner que ces deux colonnes dans l'opération.

## Partie 8 — Remplacer des valeurs aberrantes par des valeurs nulles (Find and replace)

**Scénario** : certaines mesures de `voltage_v` et `frequency_hz` contiennent des valeurs **négatives**, physiquement impossibles ici, sur des lignes pourtant marquées `status = OK` (le filtre de la Partie 4 ne les a donc pas retirées). Deux cas coexistent :

| Cas                               | Exemple  | Colonnes concernées         |
| --------------------------------- | -------- | --------------------------- |
| Code d'erreur (valeur sentinelle) | `-999.0` | `voltage_v`, `frequency_hz` |
| Erreur de signe                   | `-228.4` | `voltage_v`                 |

On ne veut pas supprimer la ligne (la consommation reste valable) : on remplace uniquement la mesure invalide par une **valeur nulle**.

### 8.1 — Repérer les valeurs négatives

```python
print("voltage_v < 0   :", (df_dedup["voltage_v"].astype(float) < 0).sum())
print("frequency_hz < 0:", (df_dedup["frequency_hz"].astype(float) < 0).sum())
```

Résultat attendu : `14` et `5` (dont `8` valeurs `-999.0` dans `voltage_v` et `5` dans `frequency_hz`).

### 8.2 — Convertir les colonnes en numérique

1. **Data** → **Launch Data Wrangler** → choisir **`df_dedup`**
2. **Change column type** → `voltage_v` → **`Decimal (float64)`** → **Apply**
3. Répéter pour **`frequency_hz`**

> 💡 Data Wrangler n'affiche l'histogramme et les statistiques (min, max, moyenne) qu'une fois la colonne castée en numérique : le minimum de `voltage_v` apparaît alors à **-999**.

### 8.3 — Remplacer le code d'erreur `-999` par une valeur nulle

1. Dans le panneau gauche, chercher **Find and replace**
2. Configurer :

| Champ             | Valeur           |
| ----------------- | ---------------- |
| **Target column** | `voltage_v`      |
| **Old value**     | `-999`           |
| **New value**     | *(vide / `NaN`)* |

3. Cliquer **Apply**
4. Répéter pour la colonne **`frequency_hz`**

> ⚠️ **Find and replace** remplace des **valeurs exactes**. Si votre version n'accepte pas une valeur vide comme remplacement, utiliser la section 8.4 (Custom operation), qui produit le même résultat.

### 8.4 — Traiter toutes les valeurs négatives (Custom operation)

Les erreurs de signe (`-228.4`) ne peuvent pas toutes être listées une à une. Utiliser **Custom operation** :

```python
import numpy as np
for col in ['voltage_v', 'frequency_hz']:
    df[col] = df[col].where(df[col] >= 0, np.nan)
```

**Ce que vous devez voir à l'écran** :

- les cellules concernées affichent `NaN`

- le résumé de `voltage_v` indique **14** valeurs manquantes, celui de `frequency_hz` **5**

- le minimum de `voltage_v` est maintenant un voltage réaliste (environ 190 V)
5. Cliquer **Add code to notebook** et adapter l'appel :

```python
def replace_negatives(df_dedup):
    for col in ['voltage_v', 'frequency_hz']:
        df_dedup[col] = df_dedup[col].astype('float64').where(df_dedup[col].astype('float64') >= 0, np.nan)
    return df_dedup

df_nonneg = replace_negatives(df_dedup.copy())
print(df_nonneg[["voltage_v", "frequency_hz"]].isna().sum())
```

> 💡 **Pourquoi `NaN` plutôt que supprimer ou mettre 0 ?** Un `0` fausserait les moyennes ; supprimer la ligne perdrait une consommation valide. `NaN` est ignoré par `mean()`, `max()`, etc. Le choix d'une imputation (médiane, interpolation) relève ensuite de la couche Silver.

## Partie 9 — Découper et fusionner du texte (Split text / Merge)

**Scénario** : `site_id` (`SITE_COM_001`) concatène trois informations : le préfixe `SITE`, le **type de site** (`COM` commercial, `IND` industriel, `RES` résidentiel) et un **numéro**. On souhaite les isoler pour filtrer et agréger par type.

### 9.1 — Découper avec Split text

1. **Launch Data Wrangler** sur **`df_nonneg`**
2. Dans le panneau gauche, chercher **Split text**
3. Configurer :

| Champ              | Valeur    |
| ------------------ | --------- |
| **Target column**  | `site_id` |
| **Delimiter**      | `_`       |
| **Maximum Number** | 2         |

4. Cliquer **Apply** et observer les trois nouvelles colonnes (`SITE`, `COM`/`IND`/`RES`, `001`/`002`)
5. Avec **Rename column**, renommer la deuxième en **`site_type`** et la troisième en **`site_num`**
6. Avec **Drop column**, supprimer la colonne contenant `SITE`

### 9.2 — Fusionner : créer un libellé lisible

Avec **Custom operation** :

```python
type_labels = {'COM': 'Commercial', 'IND': 'Industriel', 'RES': 'Residentiel'}
df['site_label'] = df['site_type'].map(type_labels) + ' #' + df['site_num']
```

5. Cliquer **Apply**, puis **Add code to notebook**

**Exemple de code** (les noms de colonnes générés par Split text peuvent varier selon la version) :

```python
def split_merge_site(df_nonneg):
    # Split text on column: 'site_id'
    parts = df_nonneg['site_id'].str.split('_', expand=True)
    df_nonneg['site_type'] = parts[1]
    df_nonneg['site_num'] = parts[2]
    # Merge: libellé lisible
    type_labels = {'COM': 'Commercial', 'IND': 'Industriel', 'RES': 'Residentiel'}
    df_nonneg['site_label'] = df_nonneg['site_type'].map(type_labels) + ' #' + df_nonneg['site_num']
    return df_nonneg

df_sites = split_merge_site(df_nonneg.copy())
display(df_sites[['site_id', 'site_type', 'site_num', 'site_label']].drop_duplicates().sort_values('site_id'))
```

**Ce que vous devez voir à l'écran** : 6 lignes, par exemple `SITE_COM_001 → COM → 001 → Commercial #001`.

## Partie 10 — Créer des colonnes calculées (formule)

**Scénario** : `consumption_MW` est une **puissance** mesurée toutes les 15 minutes. L'énergie consommée sur un intervalle est : `énergie (kWh) = puissance (MW) × 0,25 h × 1000`.

1. **Launch Data Wrangler** sur **`df_sites`**
2. Chercher **Create column from formula** (ou, si absente de votre version, **Custom operation**)
3. Configurer :

| Champ          | Valeur                               |
| -------------- | ------------------------------------ |
| **New column** | `energy_kwh`                         |
| **Formula**    | `df['consumption_MW'] * 0.25 * 1000` |

4. Cliquer **Apply**
5. Ajouter une seconde colonne, `date`, avec **Custom operation** :

```python
df['date'] = df['timestamp'].dt.date
```

6. Cliquer **Apply**, puis **Add code to notebook**

**Exemple de code** :

```python
def add_calculated_columns(df_sites):
    # Energie (kWh) sur un intervalle de 15 min
    df_sites['energy_kwh'] = df_sites['consumption_MW'] * 0.25 * 1000
    df_sites['date'] = df_sites['timestamp'].dt.date
    return df_sites

df_calc = add_calculated_columns(df_sites.copy())
display(df_calc[['timestamp', 'site_id', 'consumption_MW', 'energy_kwh', 'date']].head())
```

**Vérification** : une consommation de `0.865` MW doit donner `energy_kwh = 216.25`.

> 💡 La formule est du **Python pandas** : tout ce qui fonctionne sur une colonne (`+`, `*`, `np.where`, `.str`, `.dt`) peut y être utilisé.

## Partie 11 — Agréger avec Group by (DataFrame et fichiers séparés)

**Scénario** : produire une table **journalière par site** (consommation moyenne et maximale, énergie totale, tension moyenne), sans toucher au DataFrame détaillé `df_calc`.

### 11.1 — Agréger avec Data Wrangler

1. **Launch Data Wrangler** sur **`df_calc`**
2. Dans le panneau gauche, chercher **Group by column and aggregate**
3. Configurer :

| Champ                   | Valeur                                                                        |
| ----------------------- | ----------------------------------------------------------------------------- |
| **Columns to group by** | `site_id`, `date`                                                             |
| **Aggregations**        | `consumption_MW` → Mean, Max, Count ; `energy_kwh` → Sum ; `voltage_v` → Mean |

4. Cliquer **Apply**, puis **Add code to notebook**
5. **Important** : renommer le résultat pour conserver `df_calc` intact :

```python
def aggregate_daily(df_calc):
    df = df_calc.groupby(['site_id', 'date']).agg(
        consumption_MW_mean=('consumption_MW', 'mean'),
        consumption_MW_max=('consumption_MW', 'max'),
        consumption_MW_count=('consumption_MW', 'count'),
        energy_kwh_sum=('energy_kwh', 'sum'),
        voltage_v_mean=('voltage_v', 'mean'),
    ).reset_index()
    return df

df_daily = aggregate_daily(df_calc.copy())
display(df_daily)
print(df_daily.shape)
```

**Ce que vous devez voir à l'écran** :

- **180 lignes** (6 sites × 30 jours) et 7 colonnes
- `df_calc` (détail) et `df_daily` (agrégat) coexistent dans le notebook

## Partie 12 — Utiliser Copilot dans Data Wrangler

**Principe** : au lieu de choisir une opération ou d'écrire le code, on **décrit la transformation en langage naturel** ; Copilot génère le code pandas, affiche un aperçu, et l'on valide.

### 12.1 — Prérequis

- capacité Fabric **F2 ou supérieure** (ou P), ou essai avec votre propre ressource Azure OpenAI
- le **tenant switch Copilot** activé par l'administrateur Fabric (et, selon la région, l'autorisation de traitement inter-régions)
- sans ces prérequis, la zone Copilot n'est pas disponible : passer à la Partie 13

### 12.2 — Opération 1 : créer une colonne par description

1. **Launch Data Wrangler** sur **`df_calc`**
2. Dans le panneau gauche, ouvrir **Custom operation**
3. Dans la zone de texte **Copilot** (au-dessus de la cellule de code), saisir :

```text
Add a column named period with the value 'night' when the hour of timestamp is between 22 and 5 (inclusive of 22, exclusive of 6), otherwise 'day'
```

4. Cliquer **Run Preview** : vérifier la nouvelle colonne `period` dans l'aperçu
5. **Lire le code généré** (il doit ressembler à ce qui suit) puis cliquer **Apply**

```python
df['period'] = df['timestamp'].dt.hour.apply(lambda h: 'night' if h >= 22 or h < 6 else 'day')
```

### 12.3 — Opération 2 : détecter les valeurs atypiques par site

Nouvelle **Custom operation**, prompt :

```text
Add a boolean column is_outlier that is True when consumption_MW is greater than the mean plus 3 standard deviations of consumption_MW computed per site_id
```

1. **Run Preview**, puis contrôler la logique dans le code généré (calcul **par site**, pas global)
2. **Apply**, puis **Add code to notebook** :

```python
df_copilot = df_calc.copy()
# code généré par Copilot ici (adapter la fonction/le nom du DataFrame si besoin)
print(df_copilot['period'].value_counts())
print(df_copilot['is_outlier'].value_counts())
```

### 12.4 — Comparer et critiquer le code généré

| Question à se poser                                  | Réflexe                                                        |
| ---------------------------------------------------- | -------------------------------------------------------------- |
| Le code fait-il exactement ce que j'ai demandé ?     | Relire chaque ligne avant **Apply**                            |
| La logique est-elle par site ou globale ?            | Reformuler le prompt si ambigu                                 |
| Le résultat est-il identique à l'écriture manuelle ? | Recalculer en pandas et comparer (`.equals()`, `value_counts`) |

> 💡 **Bonnes pratiques** : nommer précisément les colonnes dans le prompt, indiquer le type attendu (booléen, texte, date), préférer des prompts courts qui ne font **qu'une chose**. Copilot peut se tromper : le code reste du Python que vous êtes responsable de valider.

> ⚠️ Les prompts en anglais donnent en général de meilleurs résultats ; l'interface et la disponibilité de Copilot évoluent régulièrement.
