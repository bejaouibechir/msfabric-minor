# Workshop: Domains and Subdomains

## Part 1 — Creating the domain

1. Click on the gear**** at the top right → **Portal Admin**
2. In the left menu, click **Domains**
3. Cliquer **Start from scratch**
4. Renseigner :

| Field             | Value        |
| ----------------- | ------------- |
| **Name**          | `EnergiaNord` |
| **Domain admins** | `Dev`         |

5. Cliquer **Create**

**What you need to see on screen**:

- field`EnergiaNord`appears in the list

## Part 2 — Creating sub-domains

## Part 3 — Creating Workspaces

### 3.1 — Workspace Finance

1. Go to [https://app.fabric.microsoft.com](https://app.fabric.microsoft.com)
2. In the left sidebar, click **Workspaces** → **+ New workspace**
3. Renseigner :

| Field           | Value                            |
| --------------- | --------------------------------- |
| **Name**        | `WS_FINANCE`                      |
| **Description** | `Workspace Finance - EnergiaNord` |

4. Choose the Finance subdomain of the Domains field
5. Choose the capacity of the chmaps capacity
6. Cliquer **Apply**

### 3.2 — Workspace Marketing

1. Cliquer **+ New workspace**
2. Renseigner :

| Field           | Value                              |
| --------------- | ----------------------------------- |
| **Name**        | `WS_MARKETING`                      |
| **Description** | `Workspace Marketing - EnergiaNord` |

3. Cliquer **Apply**

## Part 4 — Linking workspaces to subdomains

### Option A — from the Admin portal (recommended)

1. Return to **Portal admin** → **Domains**
2. Click on the field **`EnergiaNord`**
3. Click on the subdomain **`Finance`**
4. Cliquer **Assign workspaces**
5. Search and select **`WS_FINANCE`**
6. Cliquer **Assign**
7. Repeat for subdomain **`Marketing`** → assigner **`WS_MARKETING`**

### Option B — from Workspace settings

1. Open the workspace **`WS_FINANCE`**
2. Cliquer **Workspace settings** → **General**
3. In the field **Domain**, select`EnergiaNord / Finance`
4. Cliquer **Apply**
5. Repeat for **`WS_MARKETING`** → select`EnergiaNord / Marketing`

**What you need to see on screen**:

- `WS_FINANCE`related to the sub-domain`Finance`
- `WS_MARKETING`related to the sub-domain`Marketing`
- in the Admin portal, the two workspaces appear under their respective subdomains

## Part 5 — Auditing the Organization

1. Go to **Portal Admin** → **Domains**
2. Ouvrir `EnergiaNord`

**What you need to see**:

```
EnergiaNord (domaine)
├── Finance (sous-domaine)
│   └── WS_FINANCE
└── Marketing (sous-domaine)
    └── WS_MARKETING
```

> * **Interest**: Areas allow to delegate administration, apply data policies (certification, sensitivity) and filter the data catalogue by trade in Microsoft Purview.

If you reassign a workspace, it automatically leaves its previous domain.
