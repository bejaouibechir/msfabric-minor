🎯 Objective : create a base of reusable measurements (CA, margin, volumes, time, objectives) without dependent on calculated columns (which can be limited according to mode / l URI Fabric).

In the semantic model: click on Fact_OrderLines → New measure, then create the 14 measures below.
Each measure is accompanied by its purpose and DAX functions used (with links).

Basic measures (CA / costs / margin / volumes) :

Total Revenue — chiffre d’affaires total. Fonctions : SUM.

Total Revenue = SUM(Fact_OrderLines[LineTotalEUR])

Total Cost — total cost. Functions: SUM.

Total Cost = SUM(Fact_OrderLines[LineCostEUR])

Total Margin — margin in value. Functions: SUM.

Total Margin = SUM(Fact_OrderLines[LineMarginEUR])

Margin % — taux de marge (= marge / CA). Fonctions : DIVIDE.

Margin % = DIVIDE([Total Margin], [Total Revenue], 0)

🧩 Troubleshooting (circulal dependence) : si Margin % displays a circular dependence, it's almost always that Total Margin was created with a self-referential formula (e.g.: Total Margin = [Total Margin]) or that another object has the same name.
✅ Corriger Total Margin so that it is exactly: SUM(Fact_OrderLines[LineMarginEUR]), then recreate Margin %.

💡 Format : Margin % returns a decimal fraction (e.g. 0.253 = 25.3%). In Power BI, apply the format 0.0%. Do not multiply by 100 to the extent.

Nb Orders — nombre de commandes (distinct). Fonctions : DISTINCTCOUNT.

Nb Orders = DISTINCTCOUNT(Fact_OrderLines[OrderKey])

Nb Customers — nombre de clients (distinct). Fonctions : DISTINCTCOUNT.

Nb Customers = DISTINCTCOUNT(Fact_OrderLines[CustomerSK])

Avg Order Value — panier moyen (= CA / nb commandes). Fonctions : DIVIDE.

Avg Order Value = DIVIDE([Total Revenue], [Nb Orders], 0)

Mesures temporelles (comparaisons / cumul) :

Prerequisites: relationship Fact_OrderLines[DateKey] → Dim_Date[DateKey] (Bloc 7.2) and Dim_Date[FullDate] Type Date.

Revenue PY — CA N-1 over the same period. Functions: CALCULATE, SAMEPERIODLASTYEAR.

Revenue PY = CALCULATE([Total Revenue], SAMEPERIODLASTYEAR(Dim_Date[FullDate]))

Revenue YoY % — evolution of AC vs N-1. Functions: DIVIDE (+ variables VAR / RETURN).

Revenue YoY % =
VAR CurrentRevenue = [Total Revenue]
VAR PriorRevenue = [Revenue PY]
RETURN DIVIDE(CurrentRevenue - PriorRevenue, PriorRevenue, 0)

Revenue YTD — CA cumulation since the beginning of the year. Functions: TOTALYTD.

Revenue YTD = TOTALYTD([Total Revenue], Dim_Date[FullDate])

Revenue QTD — CA cumulation since the beginning of the quarter. Functions: TOTALQTD.

Revenue QTD = TOTALQTD([Total Revenue], Dim_Date[FullDate])

Target measures (sellers) :

Target Revenue — annual objective (sum of objectives). Functions: SUM.

Target Revenue = SUM(Dim_SalesRep[AnnualTargetEUR])

Target Attainment % — rate of achievement (= CA / objective). Functions: DIVIDE.

Target Attainment % = DIVIDE([Total Revenue], [Target Revenue]*100, 0)

Quality measurement (loss sales) :

Nb Loss Lines — number of sales lines with negative margins. Functions: CALCULATE, COUNTROWS.

Nb Loss Lines =
CALCULATE(
    COUNTROWS(Fact_OrderLines),
    Fact_OrderLines[LineMarginPct] < 0
)

Objective Achieved — fixed target value (100% = 1 in decimal fraction) for Gauge and KPI visuals. Functions: constant.

Target Achieved = 1

Power BI does not accept constant values entered directly in the field areas of the visuals (Target, Minimum, Maximum). A measure is required, even for a constant.

GLOSSARY OF MEASURES

Total Revenue: Sum of CA of all command lines (format: M€)
Total Margin: CA - Total cost (absolute margin)
Margin % : Total Margin / Total Revenue
Nb Orders: Number of separate commands
Nb Customers: Number of separate customers ordering
Avg Order Value : Average basket = CA / Nb commands
PY income: CA over the same period of year N-1
YoY Revenue %: CA vs N-1 evolution (+ = growth)
YTD revenue: CA accumulated since 1 January of the filtered year
QTD revenue: CA accumulated since the beginning of the filtered quarter
Target Income: Accumulated annual sales targets
Target Attainment % : Real CA / Target (100% = Target Achieved)
Nb Loss Lines: Lines sold below cost (margin < 0)
