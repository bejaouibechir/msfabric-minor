Dataflow Gen2 Workshop - Calculation of Carbon and ESG Reporting

📌 Introduction

Contexte

You are data analyticst at GreenCorp Energy, a multi-source energy producer that must comply with European ESG (Environmental, Social, Governance) regulations.

Purpose of the workshop : Create an automated pipeline to calculate the carbon footprint of the energy mix and generate regulatory ESG reports.

3 major challenges

1. Calcul d'empreinte carbone impossible

  • Production and emission factors in separate files
  • No automatic link source → CO2 emissions
  • Impact : Cannot calculate total emissions in real time

2. dirty data prevent reporting

  • Budgets → Overestimate emissions
  • Error codes -999 → Miscalculations
  • Incoherent dates → Cannot cross consumption/production

3. No steering of ESG objectives

  • No consolidated view energy mix vs 2030 targets
  • Manual calculations in Excel → Errors + 2 days delay
  • Regulatory risk : Fines if non-compliance EU Green Deal

How Dataflow Gen2 solves these problems

Proposed solution

Besoin Solution Dataflow Gen2
Calculation of CO2 emissions Joint production × emission factors
Clean data Filter error codes + deletion duplicates
Unifier dates Transformation DD/MM/YYYY → YYYY-MM-DD
Enrichir contexte Weather joint + CO2 price + ESG targets
Pilot Objectives Calculated columns (target vs. carbon cost)

Step by step implementation

Prerequisite

  • ✅ Workspace Fabric
  • ✅ Lakehouse LH_ESG_Carbon established
  • CSV files uploaded in /Files/data_esg/

STEP 1: Create Dataflow Gen2

1.1 Initialisation

  1. Workspace → + New → Dataflow Gen2
  2. Nom : DF_Calcul_Empreinte_Carbone_ESG

1.2 Management of 6 sources

  1. Get data → OneLake data hub
  2. Naviguer : Lakehouse → Files → data_esg
  3. Select 6 CSV files
  4. Create → Power Query Editor

STEP 2: Data Cleaning

2.1. Request production_sources_energie

Actions :

  1. Home → Remove Duplicates (toutes colonnes)
  2. Home → Filter Rows → production_kwh ≠ -999
  3. Home → Remove Rows → Remove Errors (production_kwh)
  4. Transform → Data Type : date → Date

Result : ~2,300 → ~2,070 lines (-10% invalid data)

2.2. Request consommation_secteurs

Actions :

  1. Transform → Data Type : date_releve → Date
    - Power Query automatically manages DD/MM/YYYYY and YYYY-MM-DD
  2. Transform → Rename : date_releve → date

Result : Unified dates

2.3 Reference requests (no cleaning)

  • facteurs_emission_reference
  • meteo_quotidienne
  • objectifs_esg_reglementaires
  • prix_certificats_co2

→ Clean data, just check types

STEP 3: Calculation of CO2 emissions

3.1 Enriching production with emission factors

  1. Select production_sources_energie
  2. Home → Merge Queries → Merge Queries as New
  3. Configuration :
    - Left table : production sources energy
    - Right table: factors emission reference
    - Colonnes : source_energie = source_energie
    - Join : Left Outer
  4. Nom : production_avec_emissions
  5. Click → Select:
    - facteur_emission_kgco2_kwh
    - categorie
    - objectif_2030_pct

Calculate CO2 emissions

Add Column → Custom Column :

Nom : emissions_co2_kg
Formule : [production_kwh] * [facteur_emission_kgco2_kwh]

Add Column → Custom Column :

Nom : emissions_co2_tonnes
Formule : [emissions_co2_kg] / 1000

STEP 4: Contextual enrichment

4.1 Add Weather Data

  1. Select production_avec_emissions
  2. Merge Queries as New :
    - Droite : meteo_quotidienne
    - Colonnes : date = date
    - Join : Left Outer
  3. Nom : production_enrichie_meteo
  4. Expand : temperature_moy_c, ensoleillement_heures, vitesse_vent_mps

4.2 Add CO2 prices

  1. Merge Queries (on production enriched meteo):
    - Droite : prix_certificats_co2
    - Colonnes : date = date
    - Join : Left Outer
  2. Expand : prix_tonne_co2_eur

4.3 Calculate the carbon cost

Add Column → Custom Column :

Nom : cout_carbone_eur
Formule : [emissions_co2_tonnes] * [prix_tonne_co2_eur]

STEP 5: Aggregation and KPIs

5.1 Create a daily aggregated view

  1. Dupliquer production_enrichie_meteo → Nom : emissions_quotidiennes
  2. Transform → Group By :
    - Grouper par : date, categorie
    - Agregations:
    • production_totale_kwh = Sum(production_kwh)
    • emissions_totales_tonnes = Sum(emissions_co2_tonnes)
    • cout_carbone_total_eur = Sum(cout_carbone_eur)

5.2. Calculate the renewable share

Add Column → Custom Column :

Nom : part_renouvelable_pct
Formule : 
let
    prod_renouvelable = if [categorie] = "Renouvelable" then [production_totale_kwh] else 0,
    prod_totale = List.Sum(#"Grouped Rows"[production_totale_kwh])
in
    (prod_renouvelable / prod_totale) * 100

Simplification si trop complexe : Create 2 separate queries (Renewable/Fossile) and calculate in Power BI

STEP 6: Joint with ESG objectives

6.1 Add column year

On emissions_quotidiennes :

Add Column → Custom Column :

Nom : annee
Formule : Date.Year([date])

6.2 Joint with objectives

  1. Merge Queries :
    - Droite : objectifs_esg_reglementaires
    - Colonnes : annee = annee
    - Join : Left Outer
  2. Expand :
    - reduction_emissions_pct
    - part_renouvelable_cible_pct
    - emissions_max_tonnes_co2

6.3 Calculate variances vs. targets

Add Column → Custom Column :

Nom : ecart_objectif_emissions_pct
Formule : ([emissions_totales_tonnes] / ([emissions_max_kg_co2] / 1000)) * 100

Add Column → Custom Column :

Nom : conforme_objectif
Formule : if [ecart_objectif_emissions_pct] <= 0 then "✅ Conforme" else "❌ Non conforme"

STEP 7: Treat consumption

7.1 Nettoyer consommation_secteurs

Already done (unified dates)

7.2 Aggregate by Date

  1. Dupliquer → Nom : consommation_quotidienne
  2. Group By :
    - Grouper par : date
    - Agregations:
    • consommation_totale_kwh = Sum(consommation_kwh)
    • nombre_sites_total = Sum(nombre_sites)

7.3 Joint production/consumption (optional)

To calculate the coverage rate:

  1. Merge production enriched + daily consumption (by date)
  2. Calculer : taux_couverture = production / consommation

KPIs ESG created

1. Empreinte carbone

  • Emissions totales 2025 : ~400,000 tonnes CO2
  • Carbon cost: ~400,000 t × 85 €/t = 34 M€
  • Par source :
  • Coal: 35% of emissions (but 25% production)
  • Gas: 45% of emissions (33% production)
  • Renewable: 20% of emissions (42% production)

2. Energy mix

  • Renewable share: 45% (objective 2025: 40%)
  • Fossil share: 55% (to be reduced to 10% by 2030)

3. Regulatory compliance

  • Emission target 2025: 500,000 t CO2 max
  • Achieved: 400,000 t CO2
  • Difference: -20% Conforme EU Green Deal

Business value

Gains quantifiables :

  • ⏱️ Time saved : 2 jours/mois × 12 = 24 jours/an manual reporting eliminated
  • 💰 Optimisation mix : Identify that coal emits 2× more than gas for equivalent production → Priority coal release strategy
  • 📊 Transparence ESG : Automatic reporting for investors and regulators
  • 🎯 Objective piloting : Real-time monitoring of the 2030 vs 2030 targets

Policy decisions permitted :
