Notebooks Workshop – Visualization

WORKSHOP 4: GOLD DATA VISUALIZATION AND ANALYSIS

The objective of the workshop

We built a complete Medallion pipeline (Bronze → Silver → Gold) to model an energy park of 6 French sites. Bronze data contained the raw measurements of 115,200 IoT sensors (30 days × 15 min). They were cleaned (Silver) and aggregated (Gold) to produce decision-ready analytical tables.

This final workshop goes through the final step: turning these Gold tables into visualisations intelligentes which tell the story of the data. We will adopt a dual pedagogical approach First Python (Matplotlib/Seaborn) to build custom graphics and finely understand the data, then Power BI to create an interactive dashboard that can be shared with the trades. This progress shows how a data scientist moves from exploratory prototype to robust analytical product.

PART 1: VISUALIZATION WITH PYTHON (Matplotlib / Seaborn)

Prerequisites

  1. Create Notebook : In your Microsoft Fabric workspace, create a new Notebook appointed NB_04_Visualization
  2. Configure Lakehouse : Define Lakehouse_gold as default Lakehouse Notebook (Section of the Notebook on Lakehouse)
  3. Check Gold tables : Via the Lakehouse Explorer, make sure the 6 tables are present:
    - gold.daily_consumption_by_site
    - gold.site_kpis
    - gold.consumption_by_site_type
    - gold.curtailment_opportunities
    - gold.monthly_consumption_pivot
    - gold.active_alerts
  4. Runtime : Make sure you have an active PySpark runtime (default Fabric environment is enough)

B. Creating measures DAX

Measurements are dynamic calculations that adapt to the ratio filters.

How to create a measure:

  1. In the panel Data (right), right click on the table daily_consumption_by_site
  2. Select Nouvelle mesure
  3. A formula bar opens on top of the canvas
  4. Delete the default text, paste the measure, press Entry
  5. Repeat for each measurement

💡 Bonne pratique : Create all the measurements in the same table to find them easily.

Mesure 1 — Consommation Totale (MWh)

Consommation Totale (MWh) =
SUM('daily_consumption_by_site'[total_consumption_mwh])

Sum of consumption over the active filtering period and context (site, date, type).

Mesure 2 — Taux de Charge Moyen (%)

Taux de Charge Moyen (%) =
AVERAGE('site_kpis'[load_factor_pct])

This measure reads directly the column load_factor_pct already calculated in site_kpis. Do not attempt to recalculate it since avg_consumption_mw / capacity_mw — these columns are not accessible in this filter context.

A > rate 70% indicates high use. Below 30%, the site is underexploited.

Mesure 3 — Gain Effacement Total (€)

Gain Effacement Total (€) =
CALCULATE(
    SUM('curtailment_opportunities'[potential_gain_eur]),
    'curtailment_opportunities'[potential_gain_eur] > 0
)

Sum of financial gains on niches where erasure is profitable (spot price > site trigger price).

Mesure 4 — Nombre d'Alertes Critiques

Nb Alertes Critiques =
CALCULATE(
    COUNTROWS('active_alerts'),
    'active_alerts'[priority] = "CRITIQUE"
)

Counts the number of maximum priority alerts. To be monitored in real time.

Mesure 5 — Taux Anomalies Glissant 7j (%)

Taux Anomalies Glissant 7j (%) =
VAR EndDate = MAX('daily_consumption_by_site'[date])
VAR StartDate = EndDate - 7
RETURN
DIVIDE(
    CALCULATE(
        SUM('daily_consumption_by_site'[nb_anomalies]),
        'daily_consumption_by_site'[date] >= StartDate,
        'daily_consumption_by_site'[date] <= EndDate
    ),
    CALCULATE(
        SUM('daily_consumption_by_site'[nb_measurements]),
        'daily_consumption_by_site'[date] >= StartDate,
        'daily_consumption_by_site'[date] <= EndDate
    )
) * 100

Do not use LastDate — it is a reserved word DAX. Use EndDate as above. Do not use DATESBETWEEN Here because the column date is not marked as date table.

Mesure 6 — Prix Spot Moyen (€/MWh)

Prix Spot Moyen (€/MWh) =
AVERAGE('daily_consumption_by_site'[avg_price_eur_mwh])

Measure 7 — Error Prediction Average (%)

Error Prediction Average (%) =
DIVIDE(
AVERAGE('daily consumption by site'[avg prediction error mw]),
AVERAGE('daily consumption by site'[avg consumption mw])
) * 100
