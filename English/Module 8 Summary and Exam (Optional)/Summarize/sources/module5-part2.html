Workshop 5 — Unstructured Data Processing

Part 2: Automated Pipeline + Critical Call Alerts

Theme: Data Factory Orchestration + Activator (Real-Time Intelligence)

Background and Context

Part 1 created the silver_appels_enrichis table with 120 manually analyzed calls.

Problem: this treatment should automatically trigger with each new incoming audio file. An operator cannot manually restart the Notebook every day.

Part 2: Build a Pipeline Data Factory that:

  1. Starts on arrival of a new file in the audio_calls/
  2. folder Process file (update of Silver table)
  3. Record an alert in the alertes_critiques table if the churn score ≥ 50 (visible in Fabric Monitor and Power BI)

Architecture of this part — 100% native Fabric

New .txt file in Files/audio calls/
▼
Pipeline Data Factory (scheduled trigger every 15 minutes)
Activity 1: Parametric Notebook (enrichment + MERGE Silver)
Activity 2: If Condition (score risk churn ≥ 50 ?)
│ ¬ YES → Set Variable & quot; ALERT" (visible Monitor) + writing table alerts critic
│ - NO → Set Variable "OK" (visible Monitor)
▼
Delta table critical alerts (consultable SQL + Power BI Part 3)

💡 Pedagogical choice: All alerts are traced to a Delta alertes_critiques table in Lakehouse. This approach is free, persistent, SQL-requestable, and directly usable in Part 3's Power BI report — without any external subscription.
