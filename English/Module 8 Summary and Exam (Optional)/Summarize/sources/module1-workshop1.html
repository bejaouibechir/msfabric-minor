Dataflow Gen2 Workshop - Harmonization of Renewable Energy Data

📌 Introduction

Contexte

You're a data engineer at GreenEnergy France, a multi-energy operator that manages:

  • 4 parcs solaires (Paris, Lyon, Marseille, Bordeaux)
  • 5 wind farms (Normandie, Brittany, Picardie, Pays de la Loire, Centre)
  • 3 hydraulic plants (Rhône, Alps, Pyrenees)

Purpose of the workshop : Create an automated pipeline to harmonize heterogeneous data and power a unified monitoring dashboard.

3 critical issues

1. Incompatible data silos

  • Different diagrams (park id vs park code vs PlantID)
  • Formats de dates multiples
  • Heterogeneous units (kWh vs MWh)
  • Impact : 2-3 hours/manual preparation day in Excel

2. Poor data quality

  • Doublons → Surestimation de 1,268 MWh = 190,200 € potential error
  • Missing values → Calculation of distorted averages
  • Error codes → Negative output recorded

3. Absence d'orchestration

  • Manual process: data available at 11.30 am (vs arrive at 6.00 am)
  • Pas de planification automatique
  • No business context (meteo, maintenance)

Step by step implementation

Prerequisite

  • ✅ Workspace Fabric
  • ✅ Lakehouse LH_Energies_Renouvelables established
  • CSV files uploaded in /Files/data_renewable/

STEP 1: Create Dataflow Gen2

1.1 Initialisation

  1. Workspace → + New → Dataflow Gen2
  2. Nom : DF_Harmonisation_Production_Renouvelable

1.2 Ingestion of the 4 sources

  1. Get data → OneLake data hub
  2. Naviguer vers : Lakehouse → Files → data_renewable
  3. Select the 4 CSV files:
    - solaire_2025.csv
    - eolien_2025.csv
    - hydro_2025.csv
    - calendrier_meteo_maintenance.csv
  4. Create → Power Query Editor s'ouvre

STEP 2: Data Cleaning

2.1. Request solaire_2025

Actions to be undertaken :

  1. Transform → Detect Data Type (types automatiques)

  2. Home → Remove Rows → Remove Errors (on production kwh)

  3. Home → Filter Rows → production_kwh ≠ -888

  4. Home → Remove Duplicates (select timestamp + park id)

  5. Transform → Rename : timestamp → date

  6. Transform → Data Type : date → Date (sans heure)

  7. Add Column → Custom Column :

Nom : rendement_pctFormule : if [irradiation_kwh_m2] > 0 then ([production_kwh] / [irradiation_kwh_m2]) * 100 else null

Result : 1,460 → 1,370 lines (-6% invalid data)

2.2. Request eolien_2025

Actions :

  1. Home → Remove Duplicates (all columns)

  2. Home → Filter Rows → etat ≠ "Duplicate"

  3. Add Column → Custom Column :

Nom : production_kwhFormule : [prod_mwh] * 1000

  1. Transform → Rename : parc_code → parc_id

  2. Add Column → Custom Column :

Nom : typeFormule : "eolien"

Result : 1,975 → 1,770 lines (-10% duplicates)

2.3 Request hydro_2025

Actions :

  1. Select PlantID column → Transform → Replace Values :
  • Chercher : -var
  • Remplacer : (vide)

  1. Transform → Data Type → Date (for ReadingDate)

  2. Home → Remove Duplicates (ReadingDate + PlantID)

  3. Transform → Rename :

  • ReadingDate → date
  • PlantID → parc_id
  • Production_kWh → production_kwh
  1. Add Column → Custom Column :

Nom : typeFormule : "hydro"

Result : 2,190 → 1,095 lines (-50% normal : fusion of variants)

2.4. Request calendrier_meteo_maintenance

Actions :

  1. Transform → Detect Data Type (automatique)

No cleaning required (clean data).

STEP 3: Fusion and enrichment

3.1 Merge the 3 energy sources

  1. Home → Append Queries → Append Queries as New
  2. Select:
    - solaire_2025
    - eolien_2025
    - hydro_2025
  3. Nom : production_all_types

Result : Unified table with harmonized diagram (date, park id, type, production kwh)

3.2 Enrich with weather/calendar

  1. Select production_all_types
  2. Home → Merge Queries → Merge Queries as New
  3. Configuration :
    - Left table: production all types
    - Right table: calendar meteo maintenance
    - Colonnes : date = date
    - Join : Left Outer
  4. Nom : production_enrichie
  5. Click on the icon
    - weekend
    - maintenance
    - pluie_mm
    - vent_mps (renommer en vent_mps_meteo)
    - jour
    - mois

3.3 Final calculated columns

Add Column → Custom Column (repeat 3 times):

1. Adjusted production :

Nom : production_kwh_ajustee
Formule : if [maintenance] = 1 then null else [production_kwh]

2. Nominal capacity :

Nom : capacite_nominale_kwh
Formule : if [type] = "solaire" then 5000 
          else if [type] = "eolien" then 10000 
          else if [type] = "hydro" then 20000 
          else null

3. Facteur de charge :

Nom : facteur_charge_pct
Formule : if [capacite_nominale_kwh] > 0 
          then ([production_kwh] / [capacite_nominale_kwh]) * 100 
          else null

STEP 4: Setting the destination

  1. Select Query production_enrichie

  2. Add data destination (bottom right) → Lakehouse

  3. Configuration :

  • Workspace: (your workspace)
  • Lakehouse : LH_Energies_Renouvelables
  • Table: production_energies_renouvelables
  • Update method : Append
  1. Publish (top right)

STEP 5: Manual test

  1. Go to Workspace
  2. Trouver DF_Harmonisation_Production_Renouvelable
  3. ⋯ → Refresh now
  4. Attendre 2-3 minutes
  5. Check: Status = "Followed"

STEP 6: Data validation

In Lakehouse :

  1. Ouvrir LH_Energies_Renouvelables
  2. Tables → production_energies_renouvelables
  3. SQL analytics endpoint → New SQL query

Validation Request :

-- Check the number of rows per type
SELECT
type,
CUNT(*) as nb lines,
MIN(date) as date min,
MAX(date) as date max
From production energy renewables
GROUP BY type
ORDER BY type;

-- Expected result:
-- eolian
-- hydro
-- solar

Check for no duplicates :

SELECT date, park id, CUNT(*) as nb
From production energy renewables
GROUP BY date, park id
HAVING COUNT(*) > 1;

-- Expected result: 0 lines

STEP 7: Orchestration with Pipeline

7.1 Create Pipeline

  1. Workspace → + New → Data pipeline
  2. Nom : Pipeline_Daily_Energy_Refresh

7.2. Add activities

  1. Activities → Dataflow → Slide on the canvas
  2. Settings → Dataflow : DF_Harmonisation_Production_Renouvelable
  3. Activities → Office365 Outlook → Send email (success notification)
  4. Connect Dataflow → Email with arrow "On Success"

7.3 Planification

  1. Home → Schedule
  2. Configuration :
    - Repeat : Daily
    - Time : 06:15
    - Time zone : (UTC+01:00) Paris
    - Start date : (aujourd'hui)

7.4 Gestion d'erreurs

  1. Select Dataflow activity

  2. Settings → Advanced :

  • Retry : 3
  • Retry interval : 60 seconds
  • Timeout : 1 hour
  1. Save → Run (test)
