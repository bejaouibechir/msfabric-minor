## Using the workshops

1. Choose your preferred language directory.
2. Open the numbered module folder.
3. Follow the workshop Markdown file and import the associated notebook or script into Microsoft Fabric when requested.
4. Keep the supplied data files and relative folder structure together; several exercises reference them directly.

The English edition translates instructional Markdown, notebook Markdown cells, and visible HTML learning content. Executable code, datasets, media, model files, and other technical assets are copied unchanged so that workshop behavior remains consistent with the French source.

## Repository coverage

The bilingual layout covers all nine numbered modules. The English tree contains 359 tracked source files, including 28 Markdown files, 34 notebooks, and 19 HTML files processed for English instructional content.
